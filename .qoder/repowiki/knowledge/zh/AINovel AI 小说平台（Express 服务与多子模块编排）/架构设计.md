server.js 是单进程编排中心：启动时依次执行 `bootstrap()`（better-sqlite3 建表 + users.json 播种超管）、`initBridge()`（加载 data/system/bridge.json 并探测上游模型），再注册路由与静态资源；所有对外请求经 BASE_PATH 前缀剥离中间件后进入 src/routes.js，由该文件统一挂载鉴权、VIP 授权、reader API、admin API 与书页闸门。
- 数据层：better-sqlite3 的 global.db 被各子模块共享（reader 存 reader_vocab/explain/quiz/tts_audio，auth 存用户/VIP/预览登记，tools 存章节大纲/正文/修订快照，services 存 bridge.json 与预览产物）。
- 运行时配置：bridgeStore 在启动时把控制台启用的 aibridge Key 注入 LLM 调用链，优先级 console > process.env > .env，且通过 whoami 探测实时显示“连到哪个模型”。
- 前端资产：public/login、admin、tts、novel 分别对应登录页、管理控制台、阅读器核心与读者站，由 server.js 按 /login /admin /tts /novel 挂载。
- iOS 客户端（ios_app）作为独立子模块，复用同一套 REST 接口而非直连数据库，形成 Web 控制台 + 移动端的双端消费模式。
