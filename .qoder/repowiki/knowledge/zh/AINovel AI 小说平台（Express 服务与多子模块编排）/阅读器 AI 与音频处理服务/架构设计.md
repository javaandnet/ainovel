模块按职责拆分为三层：
- 业务编排层 `aiService.js`：聚合所有 LLM 调用，统一实现进程内 Map 缓存 + inflight 去重 + 有界队列并发保护（MAX_CONC/MAX_QUEUE），并暴露 generateQuiz / explainSentence / explainWord / pickVocab / askQuestion / answerFeedback 等对外 API；通过 sha1 哈希把 (正文, 年龄, 语言) 作为不可变键。
- 持久缓存层：`vocabStore.js`、`explainStore.js`、`quizStore.js` 三个 Store 各自在 shared `global.db` 上维护一张表，遵循同一模式——惰性打开 DB、失败置 `_broken` 降级为纯进程内缓存、写入后按 `updated_at` 做 LRU 淘汰（MAX_ROWS 由环境变量控制）。
- 音频管线层：`ttsStore.js` 基于 `msedge-tts` 调用微软边缘接口合成 MP3，落盘到 `data/tts/<hash[:2]>/<hash>.mp3`，并通过 `silenceProbe.js`（ffmpeg silencedetect）+ `mp3Cut.js`（帧级无损裁剪）完成首尾静音修剪；`pinyin.js` 用 `pinyin-pro` 生成 ruby 标注数据。
依赖方向单向：aiService → 三个 Store；ttsStore → mp3Cut + silenceProbe；各 Store 仅依赖 better-sqlite3 与 auth/userStore 提供的 GLOBAL_DB。
