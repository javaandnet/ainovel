模块以 SwiftUI 视图 + `@MainActor ObservableObject` ViewModel 的 MVVM 分层组织：
- `ManageRootView.swift` 作为入口，通过 `LibraryViewModel`（外部）拉取作品列表，使用 `NavigationStack` + `List` 展示，并提供新建/删除整部小说的 sheet 与确认弹窗。
- `NovelManageView.swift` 是单部作品的详情页，按 Section 划分状态概览、生成动作、章节列表、发布/VIP 四个区域，并通过 `.sheet(item:)` 弹出章节大纲编辑弹层。
- `NovelManageViewModel.swift` 封装所有网络与业务逻辑，暴露 `settings/chapters/parts/share/vip/busyAction/errorMessage/infoMessage` 等 `@Published` 属性；`loadAll()` 用 `withTaskGroup` 并发加载设置、章节、分部、VIP、分享信息；长任务统一经 `busy(label, work)` 包装，失败归一化为 `errorMessage`，成功则通过 `flash()` 写入 `infoMessage`。
- `Sheets.swift` 集中两个可复用弹层：`NovelSettingsSheet`（书名/概要/正文设定 + GenCfg 字数参数）和 `ChapterOutlineSheet`（标题+构思→调用 `outlineDraft` 就地生成草稿→保存）。
依赖方向单向向下：View → ViewModel → `APIClient.shared` + `Endpoint.*`，不直接持有 API 实例；数据模型（`Novel`, `Chapter`, `Part`, `GenCfg`, `ShareResponse` 等）由上层共享。
