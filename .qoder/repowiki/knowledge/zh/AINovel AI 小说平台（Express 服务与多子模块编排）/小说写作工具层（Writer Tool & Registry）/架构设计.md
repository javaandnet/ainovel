模块由三层组成：
- `base.js` 提供最小化的 `BaseTool` shim（仅保留 name/description/parameters/context/setContext），替代原 galaclaw 的 BaseTool，使 writerTool 无需改动即可继承。
- `common/writerTool.js` 是核心实现，导出 `WriterTool extends BaseTool`，在 `execute(args)` 中按 action 分发到 saveNovelPlan / addChaptersBulk / generateOutlinesForRange / tuneWordCount / setParts / setGenConfig 等分支；通过 `createWriterDB` 操作 better-sqlite3 数据库，依赖 `../../agent/llm.js` 进行模型调用，并通过 `progressHub` 推送进度。
- `registry.js` 维护两份对外契约：`MENU_ACTIONS`（按 group 渲染前端菜单按钮）与 `AI_TOOLS`（function schema 供 LLM 单轮选择），两者共享同一组 action 语义但面向不同入口。
依赖方向单向向外：tools → agent/database/utils/services，不反向被业务代码直接引用；所有外部副作用（LLM 调用、文件写入、SQLite 事务）集中在 WriterTool 内部，registry 仅做声明式描述。
