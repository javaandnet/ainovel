- 异步操作封装在 `AuthViewModel` 中，UI 侧通过 `Task { await auth.xxx() }` 触发，避免在 View 内直接调用网络接口。
- 错误信息集中写入 `errorMessage` 属性，View 通过 `if let msg = auth.errorMessage` 条件渲染红色提示区。
- 涉及 Cookie 域变更的操作（切换服务器环境、保存自定义地址）统一调用 `auth.serverChanged()` 清理本地会话，确保重新登录。
- 可复用的 UI 片段（如 `envChip`）以私有方法形式定义在 View 内部，返回 `some View` 以保持结构体 View 的自包含性。
