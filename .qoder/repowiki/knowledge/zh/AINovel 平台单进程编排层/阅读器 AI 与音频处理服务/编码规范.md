- 持久缓存 Store 统一采用惰性打开 DB + `_broken` 标记的降级模式：建库失败后返回 null，调用方自动退化为进程内缓存，不中断业务。
- 写缓存后统一调用 `evict(d)` 按 `updated_at` 降序保留前 MAX_ROWS 行，防止匿名接口被刷导致无界增长。
- LLM 调用一律先经 `cachedGenerate` 走进程内 Map + inflight 去重 + 有界队列，内容不可变时以 sha1(语义键) 作为缓存键。
- 对外 API 对空输入直接抛 Error（如 '缺少章节内容'、'缺少词语'），保证调用方能区分参数错误与下游异常。
- 音频处理遵循「宁可保留原文件也不破坏」原则：mp3Cut 解析失败、裁剪不足阈值或剪掉超过四分之三时长时返回 null，由上层保留原始产物。
