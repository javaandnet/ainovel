- 对外暴露的公共 API 以具名 `export function` 形式提供，并附带 JSDoc 标注参数类型与返回值结构。
- 配置/枚举值集中声明为顶层常量（如 `GEN_CFG_DEFAULTS`、`OVERFLOW_MODES`、`LIMITS`），业务逻辑通过读取这些常量而非硬编码字面量来决策。
- 数值输入一律先经 `clampInt` 或显式范围检查，越界时抛出带原始值的 `Error`，不做静默取默认值。
- 路径处理统一走 `expandHome` → 占位符替换 → `path.resolve` 的顺序，并以 `path.relative` 做目录边界校验，避免 `startsWith` 前缀漏洞。
