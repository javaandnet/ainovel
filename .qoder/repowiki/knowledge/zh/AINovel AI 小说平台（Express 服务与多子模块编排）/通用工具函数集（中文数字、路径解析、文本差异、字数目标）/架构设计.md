本模块是纯函数式工具层，四个文件各自独立、互不依赖：
- `chineseNumber.js`：阿拉伯数字→中文数字映射（1–999），导出 `toChinese` / `toChineseOrdinal`，供生成侧与发布侧统一标题格式。
- `skillPathResolver.js`：统一路径解析入口，暴露 `expandHome` / `resolveSkillPath` / `checkPath` / `isPathWithin` 等纯函数，并提供 `SkillPathResolver` 类以兼容旧 `DefaultPathResolver` 的实例 API；内部通过 `{baseDir}/{workspace}/{session}/{home}` 占位符 + `~` 展开 + 相对路径基准（sessionDir > workspace > cwd）三步解析，并用 `path.relative` 替代 `startsWith` 做安全边界检查。
- `textDiff.js`：零依赖的中文正文差异计算，先按自然段+句末标点切句，再用 LCS 动态规划输出 `{type:'same'|'add'|'del', text, para}` 操作序列；超过 `SAFETY_LIMIT=400000` 单元格时退化为整段替换，避免长文预览卡死进程。
- `wordTarget.js`：集中定义每章字数目标的常量、校验与区间计算（`normalizeGenConfig` / `wordBand` / `effectiveBand` / `classifyLength` / `overflowParts` / `splitTargets`），同时兼容旧版「【每章目标字数】」文字标记。
依赖方向单向向外：仅依赖 Node 标准库（`path`/`os`）与 `fs-extra`，不被其他 utils 文件引用。
