- API 路径集中在 Endpoints.swift 中用 static let / static func 声明，与后端 routes.js 一一对应，调用方不手写字符串字面量。
- APIClient 对外只暴露泛型方法，调用方传入 Decodable 类型即可自动解析 body；无返回体的接口通过 EmptyResponse 占位。
- 所有错误经 APIError 枚举包装并实现 LocalizedError，由上层统一展示中文文案，避免在业务层直接处理 URLError/httpStatus。
- Model 字段对后端可选字段一律使用 Optional，并在 struct 上扩展 display/chaptersDesc 等计算属性供 SwiftUI 直接绑定。
- AppConfig 通过 ServerEnv 枚举 + UserDefaults 实现多环境切换，custom 档允许用户覆盖 baseURL 且 normalize 自动补 /novel 前缀。
