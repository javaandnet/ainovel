server.js 是跨子模块的运行时编排中心：启动时依次执行 bootstrap()（better-sqlite3 建表 + users.json 播种超管）、initBridge()（加载 data/system/bridge.json 并探测上游模型），再挂载 BASE_PATH 前缀剥离中间件与 src/routes.js；所有对外请求经该中间件后进入统一路由层，由 routes.js 集中挂载鉴权、VIP 授权、reader API、admin API 与书页闸门。
- 数据共享契约：better-sqlite3 的 global.db 被 reader、auth、tools、services 等子模块共同读写，形成跨子模块的数据平面。
- 配置注入契约：bridgeStore 在启动时将控制台启用的 aibridge Key 注入 LLM 调用链，优先级 console > process.env > .env，并通过 whoami 实时显示连到哪个模型。
- 前端资产契约：public/login、admin、tts、novel 分别对应登录页、管理控制台、阅读器核心与读者站，由 server.js 按 /login /admin /tts /novel 静态挂载。
- 消费模式契约：ios_app 作为独立客户端复用同一套 REST 接口而非直连数据库，形成 Web 控制台 + iOS 双端消费模式。
- 长任务契约：生成正文/补大纲/字数治理等服务端长任务按书加锁，并发提交返回 409，并通过 services 中的进程内进度事件总线向前端推送逐章状态。
