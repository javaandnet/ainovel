纯静态 HTML/CSS/JS 目录，由后端 nginx 直接暴露，按功能子目录划分：
- `index.html`：站点根入口，硬编码 `/novel/admin/` 与 `/novel/` 两个卡片跳转。
- `admin/`：基于原生 fetch + 内联 CSS 的管理控制台（dashboard/index/preview），通过相对 BASE 路径调用后端 `/api/*` 接口，统一在 `api()` 中处理 401 重定向到 `/login/`。
- `tts/`：阅读模式三件套——`reader.js` 作为稳定入口（长期缓存），带时间戳动态加载 `reader.core.js` 与 `reader.css` 实现热更新；`reader.core.js` 承载实际朗读逻辑。
- `login/`：登录页。
依赖方向单向：所有页面仅通过 HTTP 请求后端 REST API，不引用任何构建产物或模块系统。
