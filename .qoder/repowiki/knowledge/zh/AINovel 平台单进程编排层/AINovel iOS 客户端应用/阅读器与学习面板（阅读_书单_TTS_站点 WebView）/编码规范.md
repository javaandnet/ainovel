- 每个功能页面采用「View + @MainActor final class XxxViewModel: ObservableObject」配对，ViewModel 暴露 @Published 状态并由 View 通过 @StateObject 持有。
- 异步数据加载统一使用 `loading` / `errorMessage` 字段包裹 try-catch，捕获 `APIError` 后写入 `errorMessage`，View 侧据此显示 ProgressView 或 ContentUnavailableView。
- 所有 ViewModel 都通过单例 `APIClient.shared` 发起网络请求，并使用 `Endpoint.*` 构造端点，避免在 View 中直接拼接 URL。
- 对外部 URL 统一通过 `SiteWebView.relativeURL` / `absoluteSiteURL` 转换，中文路径先经 `urlPathAllowed` 百分号编码再交给 URL(string:)。
- 需要跨线程更新 UI 的回调（如 AVSpeechSynthesizerDelegate、WKNavigationDelegate）使用 `nonisolated` 方法并在内部 `Task { @MainActor in ... }` 切回主线程。
